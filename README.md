# E-Journal Bible

A responsive Bible reading and study journal for keeping Scripture, notes, prayer lists, and reading plans together.

## Use the app

Open [E-Journal Bible on GitHub Pages](https://alainacastillo.github.io/e-journal-bible/) after the first Pages deployment completes. You can also download the files and open `index.html` in a modern browser.

Your journal entries, notes, highlights, bookmarks, prayers, and preferences are saved in this browser with local storage. They do not sync to an account or server. Use the app's export and import controls to keep a backup or move data between browsers.

## Bible text

This release contains selected portions of KJV chapters from ten books. It is a sample for study and demonstration, not a complete Bible. Reference search and reading features operate on the included verses. Check the rights that apply in your jurisdiction before republishing Bible text.

## Files

The app is a static site: `index.html` loads the stylesheets, JavaScript, and favicon from the repository root. GitHub Actions publishes the root files to GitHub Pages whenever `main` receives a commit.
